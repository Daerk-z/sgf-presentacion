Acerca del proyecto

SGF es un proyecto formativo desarrollado en el programa Análisis y Desarrollo de Software (ADSO) del SENA.

El proyecto aplica las fases del ciclo de vida del software (análisis, diseño, desarrollo, pruebas e implantación) a una necesidad real: la gestión diaria de una farmacia.

Tecnologías

  • Java 21
    Lenguaje del servidor de la aplicación.
  • Spring Boot
    Framework para construir la API y la lógica de negocio.
  • SQLite
    Base de datos local en un solo archivo, sin servidor aparte.
  • React
    Biblioteca para construir la interfaz de usuario.
  • Vite
    Herramienta de desarrollo y empaquetado del frontend.
  • TypeScript
    JavaScript con tipos para un frontend más confiable.

Instalación local

El software real se instala localmente en el equipo de la farmacia y no se publica en internet. Este sitio solo presenta el proyecto con fines académicos.
